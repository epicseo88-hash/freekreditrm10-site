What Does RTP Mean?

RTP means Return to Player.

It describes a theoretical long-term return across a large number of game rounds.

Even if an implementation displayed 96% RTP, that would not mean:

  • RM100 must return RM96 during one session;
  • RM10 must return RM9.60;
  • a loss creates a future amount owed to the player;
  • the next bonus feature is due; or
  • the next spin can be predicted.
